# ИИ-ассистент по анализу отклонений «План vs Факт»

> Интеллектуальный помощник для финансовых аналитиков: загрузите план и факт — получите аналитическую записку, графики и ссылки на пункты договоров.

## 📌 О проекте

**ИИ-ассистент по анализу отклонений «план vs факт»** — это инструмент, который автоматизирует рутинную работу финансового аналитика: сравнение плановых и фактических показателей, поиск причин отклонений и подготовку аналитической записки для руководства.

Ассистент принимает на вход файлы с планом и фактом (бюджет, ДДС, себестоимость), находит отклонения, формирует гипотезы причин с помощью LLM, задаёт вопросы ответственным и — при необходимости — ссылается на конкретные пункты регламентов и договоров через RAG.

---

## ✨ Возможности

- 📥 **Загрузка данных** — Excel (.xlsx) и CSV с планом и фактом по статьям бюджета / ДДС / себестоимости.
- 📊 **Автоматический расчёт отклонений** — абсолютные и относительные отклонения, топ-N по значимости, светофорная индикация.
- 🧠 **Аналитическая записка от LLM** — где отклонения, какие гипотезы причин, какие вопросы задать ответственным.
- 📈 **Сводная таблица и графики** — waterfall, bar chart план/факт, динамика по периодам.
- 📚 **RAG по регламентам и договорам** — если отклонение связано с условиями договора или внутренним регламентом, ассистент приводит цитату и ссылку на пункт.
- 💬 **Интерактивный чат** — уточняющие вопросы по загруженным данным прямо в интерфейсе.

## 🚀 Быстрый старт

### 1. Клонирование

```bash
git clone https://github.com/your-username/plan-fact-ai-assistant.git
cd plan-fact-ai-assistant
```

### 2. Виртуальное окружение

```bash
python -m venv .venv
source .venv/bin/activate      # Linux/macOS
.venv\Scripts\activate         # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка окружения

Создайте файл `.env`:

```env
OPENAI_API_KEY=sk-...
LLM_MODEL=gpt-4o-mini
# или для локальной LLM:
# LLM_PROVIDER=ollama
# OLLAMA_BASE_URL=http://localhost:11434
# LLM_MODEL=llama3.1:8b
```

### 5. Запуск

```bash
streamlit run app/main.py
```

Откройте `http://localhost:8501` в браузере.

## 📥 Формат входных данных

**План и факт** — Excel или CSV с колонками:

| Статья              | Период   | План      | Факт      | Центр ответственности |
|---------------------|----------|-----------|-----------|------------------------|
| Маркетинг           | 2025-01  | 1 000 000 | 1 350 000 | CMO                    |
| Логистика           | 2025-01  |   800 000 |   760 000 | COO                    |
| ФОТ                 | 2025-01  | 3 500 000 | 3 620 000 | HRD                    |

**Регламенты и договоры** — PDF/DOCX, попадают в векторную базу для RAG.

## 🧪 Пример вывода

> **Отклонение: Маркетинг, 2025-01, +350 000 ₽ (+35%)**
>
> **Гипотезы причин:**
> 1. Досрочная оплата подрядчику по договору № 45/2024 (п. 4.2 — предоплата 100%).
> 2. Сезонный рост ставок на рекламные площадки.
> 3. Перенос расходов из декабря 2024.
>
> **Ссылка на документ:** Договор № 45/2024, п. 4.2 — «Оплата производится авансом в размере 100% в течение 5 рабочих дней с даты подписания акта».
>
> **Вопросы ответственным:**
> - Согласован ли перенос из декабря с финансовым блоком?
> - Есть ли резерв в бюджете Q1 на покрытие перерасхода?

## 🎯 Что демонстрирует проект

- Аналитик, который **автоматизирует собственную работу**, а не только считает в Excel.
- Практическое применение **LLM + RAG** к реальным финансовым данным.
- Полный цикл: от **сырых Excel-файлов** до **готовой аналитической записки** со ссылками на первоисточники.
- Понимание того, как **объяснить бизнесу** отклонение, а не только посчитать его.
