# Proposal: ИИ-ассистент по анализу отклонений «План vs Факт»

- **Статус:** Draft → Accepted
- **Автор:** realrvs
- **Дата:** 2026-10-09
- **Репозиторий:** ovsokolova/plan-fact-ai-assistant

## 1. Проблема

Финансовый аналитик ежемесячно тратит 8–20 часов на:
- сверку плана и факта по бюджету / ДДС / себестоимости в Excel;
- ручной поиск причин отклонений (согласования, договоры, регламенты);
- подготовку аналитической записки для руководства;
- формулировку вопросов ответственным (ЦФО).

## 2. Цель

Сократить время подготовки записки за счёт автоматизации сверки, LLM-гипотез, графиков и RAG-ссылок на пункты документов.

## 3. Границы

Входит: Excel/CSV план+факт, записка на русском, сводная таблица и графики, RAG по PDF/DOCX, Streamlit UI.
Не входит: 1С/ERP online, роли и права, мультиязычность, мобильное приложение.

## 4. Метрики успеха

| Метрика | Baseline | Target |
|---|---|---|
| Время подготовки записки | 8–20 ч | <= 30 мин |
| Полнота отклонений > 5% | ~70% | >= 95% |
| Доля отклонений со ссылкой на документ | 0% | >= 40% |
| Точность ссылок (human eval) | — | >= 90% |

## 5. Риски

- Галлюцинации LLM -> цитаты из RAG + human-in-the-loop.
- Конфиденциальность -> локальная LLM (Ollama).
- Разнородные Excel -> нормализация схемы + валидация.
- Устаревание документов -> версионирование, re-index.

## 6. Альтернативы

| Альтернатива | Почему не выбрана |
|---|---|
| Excel + макросы | Нет поиска причин и RAG |
| BI (Power BI / Superset) | Нет текстовой записки и RAG |
| Готовые FP&A | Дорого, нет RAG по своим договорам |
