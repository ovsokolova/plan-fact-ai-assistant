# ADR-0002: Вектор-стор — Chroma vs FAISS

- Статус: Accepted
- Дата: 2026-10-09

## Решение
- Dev / MVP: Chroma.
- Prod / on-prem: FAISS.
Абстракция VectorStore в src/rag.py скрывает выбор.

## Обоснование
- Chroma — минимум кода, метаданные из коробки.
- FAISS — скорость, нет внешних зависимостей.
- Оба — open-source, локально.

## Альтернативы
| Вариант | Почему нет |
|---|---|
| Pinecone / Weaviate Cloud | Приватность, стоимость |
| pgvector | Требует Postgres |
| Qdrant | Избыточен для single-user |

## Последствия
- Плюс: гибкость локально и on-prem.
- Минус: интеграционные тесты под оба бэкенда.
