# ADR-0003: UI — Streamlit

- Статус: Accepted
- Дата: 2026-10-09

## Решение
UI на Streamlit.

## Обоснование
- Быстрый старт: файлы, таблицы, графики, чат.
- Идеален для data-аналитиков.
- Легко хостить локально.

## Альтернативы
| Вариант | Почему нет |
|---|---|
| Dash | Больше кода |
| FastAPI + React | Долго, оверкилл для MVP |
| Gradio | Слабее для таблиц |
| Jupyter | Не продукт |

## Последствия
- Плюс: MVP за дни.
- Минус: ограничения кастомизации.
