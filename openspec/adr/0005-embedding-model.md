# ADR-0005: Модель эмбеддингов для русскоязычного RAG

- Статус: Accepted
- Дата: 2026-10-09

## Контекст
Документы (регламенты, договоры) — на русском. text-embedding-3-small показывает
заметно худшее качество на морфологически богатых языках, чем multilingual-модели.

## Решение
Двухрежимная схема:
- openai: text-embedding-3-large.
- local: intfloat/multilingual-e5-base (по умолчанию, MIT, 278M).
- Для MVP: local e5-base, чтобы не зависеть от внешнего API.

## Обоснование
- mE5-base обходит text-embedding-3-small на ru-бенчмарках (RuBQ, ruMTEB).
- Работает локально, без утечки данных.
- 768-dim — компактнее, чем 3072 у 3-large.

## Альтернативы
| Вариант | Почему нет |
|---|---|
| text-embedding-3-small | Слабее на русском |
| text-embedding-3-large | Дорого, 3072 dim |
| cointegrated/rubert-tiny2 | Слабее e5 |
| BGE-M3 | Тяжелее, избыточен для MVP |

## Последствия
- Плюс: качество RAG на русском, независимость от API.
- Минус: +400 МБ модель, нужен CPU/GPU при индексации.
- Минус: разный dim у openai/local -> переиндексация при смене.
