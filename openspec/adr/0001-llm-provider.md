# ADR-0001: Выбор LLM-провайдера

- Статус: Accepted
- Дата: 2026-10-09

## Решение
Поддержать два режима через LLM_PROVIDER: openai (default, gpt-4o-mini) и ollama (локальные модели).

## Обоснование
- OpenAI — быстрый старт, качество.
- Ollama — приватность.
- Абстракция LLMClient — легко добавить других.

## Альтернативы
| Вариант | Почему нет |
|---|---|
| Только OpenAI | Приватность |
| Только локальная | Качество на длинных записках |
| YandexGPT/GigaChat | Привязка к РФ-облаку |

## Последствия
- Плюс: гибкость и приватность.
- Минус: двойной набор промптов и тестов.
