# Spec: Variance Analysis

## Назначение
Расчёт отклонений план vs факт и их ранжирование.

## Функциональные требования

- FR-2.1 abs_variance = fact - plan.
- FR-2.2 rel_variance = (fact - plan) / plan (защита от plan = 0).
- FR-2.3 Светофор: green |rel| <= 5%, yellow 5–15%, red > 15%.
- FR-2.4 Ранжирование по |abs_variance| и |rel_variance|.
- FR-2.5 Агрегация по owner и по периодам.
- FR-2.6 Топ-N отклонений (default 10).

## Нефункциональные требования

- NFR-2.1 Идемпотентность.
- NFR-2.2 Детерминированность (без LLM).

## Критерии приёмки

- AC-1 План 1 000 000, факт 1 350 000 -> abs = +350 000, rel = +35%, red.
- AC-2 План 0, факт 100 -> rel = None, abs = +100, red.
- AC-3 Топ-3 по модулю абс. отклонения — по убыванию.
