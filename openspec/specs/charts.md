# Spec: Charts

## Назначение
Визуализация отклонений и динамики.

## Функциональные требования
- FR-5.1 Bar chart: план vs факт по топ-N статей.
- FR-5.2 Waterfall: вклад каждой статьи в общее отклонение.
- FR-5.3 Line: динамика по периодам (план и факт).
- FR-5.4 Все графики — Plotly, интерактивные.
- FR-5.5 Экспорт в HTML (charts/*.html).
- FR-5.6 Единая цветовая схема: green/yellow/red по status.

## Критерии приёмки
- AC-1 Given df с 3+ статьями, When bar, Then все статьи видны.
- AC-2 Given df с 1 периодом, When line, Then график не падает.
- AC-3 Экспорт: файл открывается в браузере без ошибок.
