# Spec: Data Ingestion

## Назначение
Загрузка и нормализация плана/факта из Excel/CSV.

## Функциональные требования

- FR-1.1 Поддержка .xlsx, .xls, .csv (UTF-8, CP1251).
- FR-1.2 Автоопределение колонок: account, period, plan, fact, owner.
- FR-1.3 Валидация: обязательные поля, числовой тип, отсутствие дублей (account, period).
- FR-1.4 Поддержка нескольких листов Excel.
- FR-1.5 Нормализация в pandas DataFrame с фиксированной схемой.
- FR-1.6 Ошибки валидации — человекочитаемые.

## Нефункциональные требования

- NFR-1.1 Файл <= 50 МБ обрабатывается <= 10 сек.
- NFR-1.2 Никаких сетевых вызовов при загрузке.
- NFR-1.3 Не логировать значения сумм.

## Схема DataFrame

| Поле | Тип | Обязательное |
|---|---|---|
| account | str | да |
| period | str (YYYY-MM) | да |
| plan | float | да |
| fact | float | да |
| owner | str | нет |

## Критерии приёмки

- AC-1 Given корректный xlsx, When загрузка, Then DataFrame с 5 колонками без потерь строк.
- AC-2 Given нет колонки fact, Then ошибка «Колонка fact не найдена».
- AC-3 Given дубли (account, period), Then ошибка с перечислением дублей.
