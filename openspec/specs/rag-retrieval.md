# Spec: RAG Retrieval

## Назначение
Индексация регламентов/договоров и поиск релевантных пунктов.

## Функциональные требования

- FR-4.1 Загрузка PDF/DOCX из data/docs/.
- FR-4.2 Чанкинг: 500–1000 токенов, overlap 100, метаданные (файл, страница, пункт).
- FR-4.3 Эмбеддинги: OpenAI text-embedding-3-small или intfloat/multilingual-e5-base.
- FR-4.4 Вектор-стор: Chroma (dev) / FAISS (prod).
- FR-4.5 Retrieval: top-k = 5, min_score = 0.75.
- FR-4.6 Каждый чанк — с source, page, clause.

## Нефункциональные требования

- NFR-4.1 Индексация 100 страниц <= 2 мин.
- NFR-4.2 Retrieval <= 500 мс.
- NFR-4.3 Re-index без перезапуска приложения.

## Критерии приёмки

- AC-1 Given запрос «предоплата маркетинг», Then в топ-3 есть п. 4.2 договора.
- AC-2 Given пустой индекс, Then пустой список без ошибок.
- AC-3 Каждый результат содержит source, page, clause.
