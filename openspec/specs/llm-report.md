# Spec: LLM Report Generation

## Назначение
Генерация аналитической записки на основе отклонений + RAG-контекста.

## Функциональные требования

- FR-3.1 Вход — DataFrame с отклонениями + релевантные фрагменты RAG.
- FR-3.2 Выход — структурированный отчёт: резюме, топ-N, гипотезы, ссылки, вопросы.
- FR-3.3 Утверждения о причинах — с пометкой «гипотеза», если нет цитаты.
- FR-3.4 Язык — русский, деловой стиль.
- FR-3.5 Ограничение длины: <= 800 слов.

## Нефункциональные требования

- NFR-3.1 Температура <= 0.3.
- NFR-3.2 Таймаут 60 сек; при ошибке — fallback без LLM.
- NFR-3.3 Логи без PII и сумм.

## Критерии приёмки

- AC-1 Given отклонение 35% и RAG-фрагмент, Then цитата и ссылка в отчёте.
- AC-2 Given нет RAG, Then нет ложных ссылок, только гипотезы.
- AC-3 Given ошибка LLM, Then шаблонный отчёт + предупреждение.
